 COJIM Social Media Security Extension

 Private Browser Extension for Monitoring & Securing the Ministry's Digital Presence



🙏 Overview

This project is a custom-built browser extension designed exclusively for the digital security and media integrity of Christopher Orji Ministries (COJIM). It safeguards COJIM's official YouTube and Facebook accounts against impersonation, scams, spam, and offensive content — all in real time.

> Inspired by the Prophet’s divine mandate and digital expansion, this tool ensures the ministry’s online spaces remain pure, protected, and professionally managed.



 🎯 Primary Objectives

1. Military-Grade Monitoring

The extension persistently scans COJIM’s Facebook and YouTube environments in the background — ensuring that no malicious or inappropriate comment goes unnoticed.
It identifies:

* Fraudulent donation requests
* WhatsApp scams
* Religious manipulation
* Bot-driven spam
* Phishing links


 2. Real-Time Comment Moderation

Using advanced detection techniques, it monitors:

* 🟦 Facebook comment sections
* 🔴 YouTube videos (including livestreams)

It flags and logs:

* Dangerous keywords (e.g. “WhatsApp”, “donate”, “send money”)
* Obfuscated language (e.g. “s3nd m0ney”, “wh\@ts\@pp”)
* Links and impersonation attempts
* Repeated offenders

🚨 Flagged content triggers:

* Admin notifications
* Storage in secure internal logs (locally & via Firebase)
* Translation & sentiment analysis



 3. Automated Alert & Reporting System

Each flagged message automatically:

* Triggers a browser/admin notification
* Translates content (using Google Cloud Translate)
* Classifies sentiment (positive/neutral/negative)
* Generates a structured report including:

  * Comment text
  * Platform (YouTube/Facebook)
  * Timestamp
  * Detected language and sentiment
  * Reason for flagging
  * Optional source profiling (future-ready)

 🔧 How It Works

* Content scripts scan Facebook and YouTube pages using DOM observation and mutation listeners
* Background scripts process data, classify risks, and coordinate alerts
* Data is synced with Firebase Firestore (under the private COJIM project) for secure storage
* A remote config panel allows trusted admins to manage keywords, emails, and rules
