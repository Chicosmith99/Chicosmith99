# COJIM Social Media Security Extension

**Version:** 3.0.0  
**Purpose:** Internal-use Firefox and Chrome Extension for securing COJIM’s official social media accounts with automated comment moderation, live stream detection, keyword surveillance, and real-time alerts.

---

## 🛡️ Features

- 🚨 Flags harmful or high-risk comments on **YouTube Studio** and **Facebook Pages**
- 🌍 Auto-translates flagged text via **Google Translate API**
- 🔍 Detects **spam patterns** and **high-risk religious exploitation terms**
- 🧠 Dynamic custom keyword lists via Options UI
- 🧾 Admin Dashboard for reviewing flagged data
- 🌑 Permanent Dark Mode for all interfaces
- 📬 Sends email (placeholder) + system notifications to admins
- 🗂️ Fully modular: popup, options, background, dashboard
