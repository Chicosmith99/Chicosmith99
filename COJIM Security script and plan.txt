Script Brief – Custom Browser Extension for Private Social Media Security Use For COJIM.

I want to build a private browser extension designed specifically to help monitor and secure the official social media accounts of Christopher Orji Ministries:

* YouTube Channel: [Christopher Orji Ministries - COJIM](https://www.youtube.com/@christopherorjiministriescojim)
* Facebook Page: [Christopher Orji Ministries - COJIM](https://www.facebook.com/ChristopherOrjiMinistriesCOJIM)

 Primary Goals

1. Military-Grade Account Security Monitoring
   The extension should constantly monitor both YouTube and Facebook environments, ensuring the integrity and safety of the ministry’s accounts.

2. Comment Moderation & Spam Detection

    Automatically scan and flag spam, scam messages, phishing attempts, and inappropriate content in the comment sections of:

     * Facebook posts
     * YouTube videos (both live streams and pre-uploaded content)
   * Special attention should be given to:

     * Comments with unofficial external links
     * Financial solicitation (e.g. people asking for help or giving fake donation info)
     * Impersonation or misleading accounts
   * Flagged comments should:

     * Be stored in a secure internal database
     * Notify the admin immediately
     * If possible, trace and record the source account details

3. Automated Reporting System

   * When a comment is flagged, an auto-report should be generated and sent:

     * To the YouTube admin dashboard
     * To the Facebook page admin inbox
   * Reports must include:

     * Comment text
     * Source account (username + profile link, if available)
     * Timestamp
     * Reason for flagging

4. Extension UI Design

   * Professional, clean, and intuitive interface
   * Tabs should include:

     * Whitelist Manager: for domains/links approved by the ministry
     * Flagged Content Log: showing all flagged comments, source accounts, platform, and timestamps
     * Word/Phrase Monitor: editable list of terms that trigger moderation
     * Facebook vs. YouTube Tabs: for platform-specific data and quick comparison
     * Report Summary: overview of reports generated and submitted

5. Always-On Monitoring

   * The extension must be active at all times, automatically scanning:

     * Livestream comment sections
     * Comments on already-uploaded videos/posts
     * New comments as they appear in real-time.

Project Plan.

Since Firefox extensions can’t directly access Facebook and YouTube content in the way native APIs can, the strategy will involve:

Content script injection to scan comments.

Custom logic to detect spam, scams, and prohibited links.

Background script to coordinate data storage, notifications, and reporting.

Popup UI with tabs for:

Whitelisted domains

Flagged comments & accounts

Reports

Platform-specific views (YouTube/Facebook)
